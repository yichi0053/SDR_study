#### sine wave:
	x(t) = A · sin(2πft + φ)
		- A : Amplitude(振幅)
		- f : frequency(頻率)
		- φ : phase(位移相位)
- Fourier 證明：任何訊號皆可被分解成不同頻率的 sine wave 相加

#### discrete signal:
	x[n] = A · sin(2π · f · (n/fs) + φ)
	     = A · sin(2π · (f/fs) · n + φ)
		 - 連續訊號用圓括號 x(t)，離散訊號用方括號 x[n]。

#### normalization frequency
- f 和 fs 從來不單獨出現，只以 **f/fs** 這個比值出現。
- 決定 discrete sequence 長相

#### Nyquist–Shannon Sampling Theorem
	fs > 2 · f_max
- 確保有足夠資訊重建原ㄈ訊號	


## Day 1 驗收問題完整解答

### 問題一：取樣率不足時，波形發生了什麼事

100 Hz 訊號以 fs = 150 Hz 取樣，此時 fs/f = 1.5，違反 Nyquist–Shannon sampling theorem（取樣定理，要求 fs > 2f）。

取樣後的離散序列，不再表現為 100 Hz，而是表現為一個更低頻率的訊號，這個現象稱為 aliasing（混疊）。原始的 100 Hz 資訊在取樣當下已經永久遺失，數位序列本身無法區分「原本就是這個低頻」還是「高頻被混疊下來」。

---

### 問題二：sin 改為 cos，在 fs = 2f 時結果為何不同

#### 推導

fs = 2f 時，f/fs = 0.5，代入 `x[n] = sin(2π·0.5·n) = sin(πn)`：

```
n=0: sin(0)  = 0
n=1: sin(π)  = 0
n=2: sin(2π) = 0
n=3: sin(3π) = 0
```

換成 cos，`x[n] = cos(πn)`：

```
n=0: cos(0)  = 1
n=1: cos(π)  = -1
n=2: cos(2π) = 1
n=3: cos(3π) = -1
```

#### 兩種失敗模式

**sin：訊號完全消失（total signal loss）**  
全部樣本為 0，取樣時間點恰好都落在訊號的 zero-crossing（零交越點）上，離散序列完全看不出原訊號存在過。

**cos：振幅保留，頻率不可辨識**  
序列在 1 與 -1 之間跳動，極值有被抓到，振幅資訊保住了。但單獨看這串數字，無法判斷原訊號頻率是 f，還是 3f、5f、7f 等在同一取樣率下會產生相同交錯序列的其他頻率，頻率的 identifiability（可識別性）沒有保住。

#### 結論：為何定理必須是嚴格不等式

fs = 2f 這個邊界上，訊號能否被正確捕捉，完全取決於取樣時間點相對於訊號相位的對齊方式：對齊到零交越點則訊號消失，對齊到極值點則頻率不可辨識，其餘相位則介於兩者之間。定理寫成 `fs > 2f` 而非 `fs ≥ 2f`，是因為只有嚴格大於才能保證無論相位為何，都有足夠資訊完整重建原訊號。

### 問題三：10 kHz 噪音混入 16 kHz 取樣的語音錄音

#### Nyquist frequency 與判定

```
Nyquist frequency = fs / 2 = 16000 / 2 = 8000 Hz
```

10 kHz 超過 8 kHz，違反取樣定理，會發生 aliasing。

#### 折疊位置

```
折疊頻率 = fs - f = 16000 - 10000 = 6000 Hz
```

10 kHz 噪音取樣後會偽裝成 6 kHz 成分。

#### 是否落在語音主頻帶

人聲主要能量集中在 300 Hz 至 3400 Hz，6 kHz 不在此範圍內，但與齒擦音（sibilance）等高頻子音的延伸能量範圍（可達 8 kHz 附近）有部分重疊。

#### 能否事後濾除：不能

取樣這個動作把「原本場景中真實存在的 6 kHz 成分」與「從 10 kHz 折疊下來的噪音」疊加成同一組數字，兩者在取樣當下已不可逆地混合。事後對數位訊號套用 6 kHz 附近的濾波器，會將真假成分一併濾除，無法區分。

這是 anti-aliasing filter（抗混疊濾波器）必須放在 ADC 之前而非取樣後處理的原因：濾波器須在類比訊號仍保有完整資訊、超過 Nyquist frequency 的成分尚未與其他頻率共用數位頻率位置時，就先行濾除。
