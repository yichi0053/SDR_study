#### Time-Frequency Properties:
1. 線性 Linearity
```
	a·x(t) + b·y(t)  ↔  a·X(f) + b·Y(f)
```
- 在時間上加總兩個信號，在頻域中也是對應的兩個信號相加。

2. 頻率平移 Frequency Shift (Modulation)
```
	x(t) · exp(j·2π·f₀·t)  ↔  X(f - f₀)
```
- 時域乘上一個複數指數（＝乘上一個頻率為 f₀ 的複數 sine wave），等於頻域上整個頻譜平移 f₀。
- 接收機把 GHz 級的無線電訊號「downconvert（降頻）」到基頻（baseband）處理。

3. 時間縮放 Scaling in Time
```
	x(a·t)  ↔  (1/|a|) · X(f/a)
```
- 時域壓縮（a > 1，訊號變快），頻域會展開（頻率範圍變寬）；反之頻域會壓縮。

4. 捲積性質 Convolution
```
	x(t) * h(t)  ↔  X(f) · H(f)  （`*` 代表 convolution，時域上的卷積，不是乘法）
```
- 時域上的卷積，等於頻域上的乘法。這條性質是 filtering（濾波）的數學基礎：對訊號套用一個 filter，時域上是把訊號與 filter 的 impulse response（脈衝響應）做卷積,但頻域上只需要把兩者的頻譜相乘,乘法遠比卷積好算。
- 透過在時域進行捲積運算，達成 masking，屏蔽掉噪音。

5. 頻域捲積性質 Convolution in Frequency
```
	x(t)·y(t)  ↔  ∫ X(g)·Y(f-g) dg
```
- Convolution 反過來也是成立的。


#### 離散傅立葉變換（DFT, Discrete Fourier Transform）
- O(N^2)
- 一段時域訊號 x(n)，裡面包含哪些頻率成份、各自強度多少。

#### 快速傅立葉變換（FFT, Fast Fourier Transform）
- DFT的快速算法。O(N logN)
- 把時域上混雜在一起、肉眼無法分辨的頻率成份，轉換成頻域上可以逐條辨識的訊息。

#### Windowing
- window function 是在兩端衰減至零的函數。確保信號相乘後從零開始並在零結束，以相互連接
- 不用 window funciton 稱為：rectangular window

## Spectral Leakage 筆記

---

### 定義

Spectral leakage（頻譜洩漏）指的是：對一段有限長度的訊號做 FFT 時，能量從理論上該集中的頻率，「漏」到周圍其他不該有能量的頻率上，導致頻譜出現原本不存在的成分。

---

### 成因

#### 根本原因：有限長度截取

真實訊號是連續、無限長的，但 FFT 只能處理有限長度的資料。從無限長訊號中截取一段長度為 duration 的資料，數學上等同於把原訊號乘上一個「範圍內是 1、範圍外是 0」的矩形窗（rectangular window），即使你完全沒有主動加窗，這個矩形窗依然隱含存在。

#### 數學機制：Convolution in Frequency Property

```
x(t) · w(t)  ↔  X(f) * W(f)
```

時域上的乘法（訊號乘上窗函數），對應頻域上的卷積（convolution）。原本應該是一根乾淨窄尖峰的 X(f)，被拿去跟矩形窗自己的頻譜 W(f) 做卷積。矩形窗的頻譜本身不是一根乾淨尖峰，而是中間有主瓣（main lobe）、兩側拖著一長串緩慢衰減旁瓣（sidelobe）的形狀（sinc 函數）。卷積的結果，就是把這個帶旁瓣的形狀「印」到原本的尖峰位置上。

#### 觸發條件：邊界不連續

若擷取的訊號片段，結尾處剛好包含整數個週期，把這段訊號無限重複貼接，銜接處是平滑連續的，洩漏效應會降到最低（d03：duration=1.0、f=50Hz，剛好 50 個完整週期）。

若擷取片段包含非整數個週期，波形會在結尾處停在振幅中途某個任意值，無限重複貼接時銜接處會出現突兀跳動（d05：duration=0.213、f=50Hz，10.65 個週期）。這個不連續的跳動，在頻域上會被解讀成「除了原頻率外還存在其他頻率成分」，因為真正純淨、無限延續的單一頻率訊號不會有任何跳動。這個因邊界不連續而「無中生有」的假頻率成分，正是洩漏能量的直接來源。

真實世界中，訊號頻率通常未知（若已知就不需要做 FFT 分析），因此「非整數週期」才是常態，「剛好整除」反而是特例。

---

### 現象

#### 在頻譜圖上的表現

以 d05 為例，50 Hz 純音經 FFT 後：

- 主峰仍出現在 50 Hz 附近，高度大致正確
- 主峰兩側並未乾淨地降到底，而是拖著一長串忽高忽低的鋸齒狀波紋，緩慢衰減，延伸到很遠的頻率才真正貼近底部
- 用線性刻度觀察不易察覺（旁瓣數值太小，被壓縮成貼近 0 的一條線），需轉換成 dB 刻度（`20*log10(magnitude)`）才能清楚看見旁瓣的相對強弱差異

#### dB 刻度下的讀圖注意事項

dB 刻度是對數轉換，magnitude 趨近 0 時，dB 值趨近負無窮大，不是趨近 0。因此背景「沒有能量」的區域，在 dB 圖上表現為持續下降到很負的數值（如 -60、-80 dB），而非貼齊 y=0 那條線。觀察重點是**下降速度的快慢**，不是「是否貼齊某條水平線」。

---

### 解法：Windowing

用一個頭尾平滑趨近 0、中間接近 1 的窗函數（如 Hann window）取代矩形窗，乘上原始訊號後，不論訊號在邊界處停在哪個振幅值，乘上接近 0 的權重都會被壓低到接近 0，邊界不連續的跳動被削弱，卷積效應印上去的旁瓣隨之減少。

#### Trade-off（代價）

Hann 窗本身的頻譜主瓣天生比矩形窗寬，卷積後主峰本身會變寬、變矮一點。換言之：**壓低旁瓣（減少洩漏）與維持主瓣窄（維持頻率解析度）無法同時兼得**，windowing 是在兩者之間做選擇，不是沒有代價的萬能解法。

---

### 完整因果鏈

```
訊號必須截取有限長度才能做 FFT
    ↓
截取 = 隱含乘上矩形窗
    ↓
截取邊界通常不連續（非整數週期，真實情況的常態）
    ↓
矩形窗的寬旁瓣頻譜，依 Convolution in Frequency Property 污染原頻譜
    ↓
產生 spectral leakage：能量漏到不該存在的頻率上
    ↓
解法：換用平滑衰減的窗函數（如 Hann），削弱邊界不連續
    ↓
代價：主瓣變寬，頻率解析度略為犧牲
```
